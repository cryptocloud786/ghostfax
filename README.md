# GHOSTFAX — Teletext, risen from the grave

> Ceefax died on 23 October 2012 at 23:32. GHOSTFAX brings it back.

**Live demo:** https://cryptocloud786.github.io/ghostfax/

GHOSTFAX resurrects the BBC Ceefax teletext service as a modern, installable web app. It renders live news, weather, history, markets and live subtitles on an authentic 40×24 character grid — no ads, no tracking, no infinite scroll. The whole app is a few hundred KB and works offline from cache.

---

## Who it is for

- **Calm-digest readers** who want glanceable news and data without feeds or distractions.
- **Low-bandwidth / low-end-device users** — the app is tiny and fully cached after first load.
- **Keyboard and TV-remote users** — every page is reachable by typing a 3-digit page number; colour Fastext buttons give one-key navigation.
- **Deaf and hard-of-hearing users** — page 888 (the classic subtitles page) shows live captions from the microphone.

## Page directory

| Page | Section | Description |
|------|---------|-------------|
| 100  | INDEX   | Directory of all sections |
| 101–104 | NEWS | In the News (Wikipedia featured feed) |
| 110–114 | TECH | Top stories from Hacker News |
| 199  | HELP    | Keyboard shortcuts and page guide |
| 300  | WEATHER | 24-hour sextant bar chart + 5-day forecast (Open-Meteo) |
| 400  | HISTORY | On This Day (Wikipedia) |
| 500  | MARKETS | BTC / ETH / SOL prices in USD and INR (CoinGecko / Coinbase) |
| 666  | GHOST   | Ghost of Ceefax — mosaic art, Ceefax obituary, Halloween countdown |
| 700  | WRITER  | Ghost Writer — type on the teletext grid; share via URL hash |
| 888  | SUBS    | Live subtitles via Web Speech API |

## Keyboard / remote map

| Key | Action |
|-----|--------|
| `0–9` | Enter a page number (3 digits) |
| `Enter` | Confirm page number |
| `Backspace` | Cancel digit entry |
| `↑` / `↓` | Page + / Page − |
| `F1` / `Q` | Red Fastext button |
| `F2` / `W` | Green Fastext button |
| `F3` / `E` | Yellow Fastext button |
| `F4` / `T` | Cyan Fastext button |
| `H` | Hold / unhold subpage carousel |
| `R` | Reveal hidden answers |
| `X` | Exorcise — disable CRT effects |
| `I` | Index (page 100) |

## Run locally

```bash
# Serve from repo root (no build step needed)
python3 -m http.server 8000
# then open http://localhost:8000
```

Or use any static file server — the app is plain HTML + CSS + native ES modules.

---

## Run tests

```bash
npm test                        # node:test unit + fast-check property tests
node scripts/grid-lint.mjs      # verify every page is exactly 24×40
node scripts/make-icons.mjs     # (re-)generate PWA icons
```

Requirements: Node 22+.

## Project structure

```
index.html              App shell (TV + remote)
manifest.json           PWA manifest
service-worker.js       Cache-first shell + network-first API
styles/ghostfax.css     CRT + teletext styling
assets/
  fonts/bedstead.otf    Teletext font (Bedstead, public domain)
  icons/                PWA icons (192 px + 512 px, generated by scripts/)
src/
  teletext/             Pure modules: grid, wrap, mosaic, router
  pages/                Pure page builders: (data, ctx) => Page[]
  data/                 fetcher.js + one adapter per data source
  ui/                   DOM renderer, keypad, remote, speech, clock
tests/
  *.test.js             node:test unit + fast-check property tests
  fixtures/             JSON fixtures for normaliser tests
scripts/
  grid-lint.mjs         Verifies 24×40 invariant on all registered pages
  make-icons.mjs        Generates PNG icons using only node:zlib
.kiro/
  specs/ghostfax/       Spec, requirements, design, tasks
  steering/             Coding rules applied automatically
  hooks/                Agent hooks (grid guardian, fixture refresh, a11y, spec sync)
  agents/               ghost-builder agent definition
  settings/mcp.json     fetch MCP server
```

## Built with Kiro

This project was built spec-first with [Kiro](https://kiro.dev), mostly via the Kiro CLI and the custom `ghost-builder` agent. Some UI glue was hand-written while Kiro was throttled; KIRO.md lists exactly which files.

The `.kiro/` directory is committed alongside the code and contains everything Kiro used to build GHOSTFAX:

| Path | Contents |
|------|----------|
| `.kiro/specs/ghostfax/` | Full spec (requirements, design, task checklist) |
| `.kiro/steering/` | Coding rules injected into every session: teletext style, tech constraints, product definition |
| `.kiro/hooks/` | Agent hooks: Grid Guardian, Fixture Refresh (MCP fetch), Accessibility Mirror Check, Spec Sync |
| `.kiro/settings/mcp.json` | fetch MCP server used to inspect live APIs and capture fixtures |
| `.kiro/agents/` | Ghost-builder agent — used for large page-builder generations |

See [KIRO.md](KIRO.md) for a walkthrough of how Kiro was used.
